# Changelog

## v0.1.0 (2026-08-16)

Initial public release.

### Features

- Convert indented selections into directory trees with `:Arb c`
- Live tree editing: automatic connectors, Tab/Shift-Tab levels,
  Backspace/dd deletion, o/O siblings, J joins
- Tree-aware visual mode, operators, and linewise paste protection
- Buffer-local tree mappings: user mappings outside trees are untouched
- Lazy-loading setup for `:Arb`, `:ArborealConvert`, and content detection
- Tests, StyLua, Luacheck, and CI for Neovim 0.9 / 0.10 / stable
